SUPER WRESTLERS — OFFLINE MOBILE GAME

1) Upload ALL files and folders in this package to the ROOT of a GitHub repository.
   index.html must be visible in the repository root.
2) Enable GitHub Pages: Settings > Pages > Deploy from a branch > main > /(root) > Save.
3) Open the GitHub Pages URL on your phone.
4) Rotate the phone to LANDSCAPE.
5) The game runs locally in the browser and does not need an online multiplayer server.

Features in this build:
- Offline single-player vs computer bot.
- 32 selectable original stylized fighter portrait SVGs.
- 8 arena color themes.
- Landscape mobile layout and touch controls.
- Player and bot portraits shown during each fight.
- Enemy bot difficulty increases by level.

Note: This is a 2D fighting prototype, not finished realistic 3D graphics. The game uses original vector portrait artwork stored locally, so the portraits do not depend on external image links.
